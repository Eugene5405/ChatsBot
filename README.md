# Чат бот

Модерация группы: приём заявок с проверкой подписки на канал, приветствие с правилами, предупреждения (сгорают через 30 дней), муты, баны, автомодерация.

## Переменные окружения (для Render)
- `BOT_TOKEN` — токен от @BotFather
- `DATABASE_URL` — ссылка подключения к PostgreSQL (например, из Neon.tech)
- `CHANNEL_ID` — ID канала для проверки подписки (необязательно)
- `LOG_CHAT_ID` — ID чата для логов наказаний (необязательно)
