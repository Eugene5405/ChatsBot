# 🛡 Хранитель чата — Telegram-бот для модерации, игр и экономики

Многофункциональный Telegram-бот на **Python 3.11+ (`aiogram 3`)** и **PostgreSQL (Neon)** с встроенной веб-панелью управления (**Telegram Mini App**). Сочетает строгую автомодерацию, систему репортов с кнопками для админов, репутацию, валюту «Алиби», магазин на 13 товаров, ролеплей и русскую рулетку.

---

## ✨ Возможности

* **Автомодерация:** умный антимат (ловит замаскированный мат и латиницу), антиспам, блокировка сторонних ссылок.
* **Модерация с защитой:** бан, мут, кик и предупреждения (ответом на сообщение или по `@username`). Предупреждения автоматически сгорают через **30 дней**, а купленные в магазине щиты спасают от наказания.
* **Репорты с уведомлением в ЛС:** участники жалуются ответом на нарушение, а админам в личку приходит карточка со ссылкой на сообщение и кнопками быстрого действия (**Удалить**, **Мут 1ч**, **Бан**, **Отклонить**).
* **Режим тишины (`-чат` / `+чат`):** мгновенное закрытие и открытие общения в группе для обычных участников.
* **Экономика «Алиби» и Магазин (13 товаров):** щиты от мута/преда/бана, снятие варна, *Swear pass*, *VIP-статус*, заказной мут, кастомный префикс, закреп на час, фейк-бан, брак, лутбокс и глушилка.
* **Репутация и порог админа:** повышение и понижение репутации с уведомлением при достижении **100 репутации**.
* **Ролеплей и Русская рулетка:** встроенные и кастомные РП-команды с кулдауном 24 часа и настраиваемая русская рулетка.
* **Telegram Mini App (`/webapp`):** управление чатами, переключатели модулей, кнопки `-чат`/`+чат` и редактор правил прямо в Telegram.

## 👥 Команды для участников

| Команда / Триггер | Как использовать | Описание |
| :--- | :--- | :--- |
| `репорт <причина>` | Ответом на сообщение | Отправляет жалобу администраторам в ЛС со ссылкой на сообщение |
| `мешок` или `/bag` | В чате | Показывает баланс «Алиби», репутацию, VIP-статус и инвентарь |
| `дать <сумма>` или `/give <сумма>` | Ответом на сообщение | Переводит указанное количество «Алиби» другому участнику |
| `магазин` или `/shop` | В чате | Открывает интерактивный магазин на 13 товаров |
| `+`, `+реп`, `+rep` | Ответом на сообщение | Повышает репутацию участника на +1 (раз в час) |
| `/lookrep` | В чате или ответом | Показывает текущую репутацию (при 100+ открывается заявка в админы) |
| `русская рулетка` | В чате | Испытать удачу: при выживании начисляются «Алиби», при проигрыше — мут |
| `обнять`, `дать леща`, `поцеловать`, `выкинуть в окно`, `укусить`, `дать пять`, `ударить` | Ответом на сообщение | Выполняет ролеплей-действие (кулдаун 24 часа, для VIP — 12 часов) |
| `/rules` | В чате | Показывает актуальные правила группы |
| `/info` | В чате или ответом | Показывает краткую информацию о пользователе |

## 👑 Команды для администраторов

| Команда | Как использовать | Описание |
| :--- | :--- | :--- |
| `-чат` / `+чат` | В чате | Закрывает / открывает чат для обычных участников (пишут только админы) |
| `варн [причина]` или `/warn @user` | Ответом или по `@username` | Выдаёт предупреждение (3/3 = бан на 3 дня; сгорают через 30 дней) |
| `анварн` или `/unwarn` | Ответом или по `@username` | Снимает последнее предупреждение |
| `мут [время]` или `/mute @user 30м` | Ответом или по `@username` | Ограничивает отправку сообщений (`м` — минуты, `ч` — часы, `д` — дни) |
| `анмут` или `/unmute` | Ответом или по `@username` | Снимает мут с участника |
| `бан` или `/ban @user` | Ответом или по `@username` | Блокирует участника в группе |
| `анбан` или `/unban @user` | Ответом или по `@username` | Разблокирует участника |
| `кик` или `/kick @user` | Ответом или по `@username` | Исключает участника из группы без перманентного бана |
| `-`, `-реп`, `-rep` | Ответом на сообщение | Понижает репутацию участника на -1 |
| `/setrep <число>` | Ответом на сообщение | Устанавливает точное значение репутации |
| `/setcreds <сумма>` | Ответом на сообщение | Устанавливает баланс «Алиби» участнику |
| `/newrp <название>` | В чате | Создаёт новую РП-команду для чата |
| `/delrp <название>` | В чате | Удаляет пользовательскую РП-команду |
| `/enablerp` / `/disablerp` | В чате | Включает или выключает модуль ролеплея |
| `/change <число>` | В чате | Меняет шанс проигрыша в русской рулетке (`1 к N`) |
| `/changemute <минуты>` | В чате | Меняет длительность мута за проигрыш в рулетке |
| `/enable` / `/disable` | В чате | Включает или выключает русскую рулетку |
| `/settings` | В чате | Открывает меню переключателей фильтров в Telegram |
| `/setrules` / `/resetrules` / `/pinrules` | Ответом / в чате | Обновляет, сбрасывает или закрепляет правила группы |
| `/status` | В чате | Проверяет права бота в группе и канале |

## 🚀 Быстрый запуск за 0 рублей (GitHub + Neon + Render + cron-job.org)

1. **Создай бота в Telegram.** Открой [@BotFather](https://t.me), создай бота через `/newbot`, скопируй `BOT_TOKEN` и в **Bot Settings → Group Privacy** выбери **Turn off**, чтобы бот видел русские команды без слэша.
2. **Создай базу данных в Neon.** Зарегистрируйся на [neon.tech](https://neon.tech), создай бесплатный проект PostgreSQL и скопируй строку подключения `postgresql://...`. Таблицы создадутся автоматически при первом запуске.
3. **Задеплой на Render.** Создай **Web Service** на [render.com](https://render.com), подключи этот репозиторий и укажи:
   * **Build Command:** `pip install -r requirements.txt`
   * **Start Command:** `python main.py`
4. **Добавь переменные окружения (Environment Variables) на Render:**
   * `BOT_TOKEN` — токен бота из `@BotFather`
   * `DATABASE_URL` — строка подключения из Neon
   * `CHANNEL_ID` — ID канала для проверки подписки (необязательно)
   * `OWNER_ID` — твой Telegram ID для уведомлений о добавлении бота в чаты
5. **Настрой пингер 24/7.** Создай бесплатную задачу на [cron-job.org](https://cron-job.org), которая каждые 5–10 минут обращается к `https://<твой-сервис>://`, чтобы сервер не засыпал.
