# 🛡 Chat Custodian Bot — Telegram Модератор и Админ-Панель

Многофункциональный Telegram-бот для модерации групп и супергрупп с встроенным **Telegram Mini App (Web App)**, умным фильтром мата, проверкой подписки на канал при подаче заявок и режимом тишины в стиле Ириса.

---

## ✨ Возможности

- **Умный антимат (`profanity.py`):** распознаёт нецензурную лексику внутри любых предложений, с заменой букв на латиницу (`c -> с`, `a -> а`), повторами букв и разделителями, не задевая нормальные слова.
- **Режим тишины (`chat_lock.py`):** команды `-чат` (закрыть чат — писать могут только администраторы) и `+чат` (вернуть общение всем участникам).
- **Проверка подписки и приветствия (`welcome.py`):**
  - Автоматически одобряет заявки на вступление только после подписки на указанный канал.
  - Отправляет приветствие с подстановкой реального названия чата и сворачиваемыми правилами.
  - Прощается с участниками при выходе и присылает уведомление в личку при добавлении/удалении бота из группы.
- **Админ-панель Telegram Web App (`webapp.py`):** управление модулями защиты по каждому подключённому чату прямо внутри Telegram.
- **Бесплатный хостинг 24/7:** работает на связке **GitHub + Render (Free Web Service) + Neon (PostgreSQL) + cron-job.org**.

## 🚀 Пошаговая инструкция по запуску (за 0 ₽)

### 1. Создание бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) и выполните `/newbot`.
2. Скопируйте полученный **HTTP API Token** (`BOT_TOKEN`).
3. В настройках бота (`/mybots` → **Bot Settings** → **Group Privacy**) нажмите **Turn off**, чтобы бот мог видеть все сообщения в группах и фильтровать нарушения.

### 2. Создание бесплатной базы данных (Neon)
1. Зарегистрируйтесь на [neon.tech](https://neon.tech) и создайте новый проект.
2. В окне **Connect** выберите формат **Connection string**, нажмите **Show password** и скопируйте ссылку вида:
   `postgresql://user:password@ep-xxx.neon.tech/neondb?sslmode=require`

### 3. Деплой на Render
1. Сделайте Fork этого репозитория на свой аккаунт GitHub.
2. Зайдите на [render.com](https://render.com), нажмите **New + → Web Service** и подключите ваш репозиторий.
3. Укажите параметры сборки:
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python main.py`
   - **Instance Type:** `Free`
4. В разделе **Environment Variables** добавьте переменные:

| Переменная | Обязательно | Описание |
| :--- | :---: | :--- |
| `BOT_TOKEN` | Да | Токен бота от `@BotFather` |
| `DATABASE_URL` | Да | Строка подключения PostgreSQL из Neon |
| `CHANNEL_ID` | Нет | ID канала для проверки подписки (например, `-1001234567890`) |

5. Нажмите **Deploy Web Service**. После перехода в статус **Live** скопируйте публичный URL сервиса (например, `https://your-bot.onrender.com`).

### 4. Защита от засыпания (cron-job.org)
Бесплатный тариф Render усыпляет сервис после 15 минут неактивности. Чтобы бот работал круглосуточно:
1. Зарегистрируйтесь на [cron-job.org](https://cron-job.org).
2. Нажмите **Create cronjob**, вставьте ваш URL с Render (`https://your-bot.onrender.com`) и выберите расписание **Every 10 minutes**.

## 📋 Основные команды

### В группе (для администраторов)
- `-чат` — закрыть чат для обычных участников (пишут только админы)
- `+чат` — открыть чат для всех
- `/status` — проверить права бота и синхронизировать чат с базой
- `/settings` — открыть настройки модерации в чате
- `/setrules` — задать правила группы (ответом на сообщение с текстом правил)
- `/warn`, `/mute`, `/ban` — выдать предупреждение, мут или бан

### В личных сообщениях с ботом
- `/start` — открыть главное меню с кнопками
- `/help` — справка по настройке и командам
