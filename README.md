# 🛡 Хранитель чата (`@chat_custodian_bot`)

Многофункциональный Telegram-бот для модерации групп и супергрупп на базе **aiogram 3**, **PostgreSQL (Neon)** и встроенной админ-панели **Telegram Mini App** с бесплатным хостингом 24/7 на **Render + cron-job.org**.

---

## ✨ Возможности бота

* **🚨 Система репортов (как в Ирисе).** Участник отвечает на сообщение нарушителя командой `репорт <причина>` — бот отправляет уведомление в чат, а всем администраторам в личку присылает карточку жалобы со ссылкой на сообщение и кнопками быстрого наказания (**Удалить**, **Мут 1ч**, **Бан**, **Отклонить**).
* **🔒 Режим тишины (`-чат` / `+чат`).** Мгновенное закрытие общения в группе для обычных участников (писать могут только админы) и обратное открытие чата.
* **🤬 Умный антимат и автомодерация.** Фильтрация нецензурной лексики внутри любых предложений (включая замену на латинские буквы, пробелы и повторы символов), защита от флуда и блокировка сторонних ссылок.
* **⚖️ Система наказаний.** Варны с автоматическим баном при достижении `3/3`, временные муты (`10м`, `2ч`, `1д`), кик и бан с поддержкой команд как через `/`, так и обычными словами ответом на сообщение.
* **👋 Приветствия, прощания и проверка подписки.** Встречает новичков с реальным названием группы и сворачиваемыми правилами, прощается при выходе участника, а при входе по заявкам проверяет подписку на указанный канал.
* **📱 Встроенная админ-панель (Telegram Web App).** Современный интерфейс внутри Telegram для переключения фильтров, управления режимом тишины (`-чат` / `+чат`), редактирования правил и удаления чатов из списка.

## 👥 Команды для участников

| Команда | Как использовать | Описание |
| :--- | :--- | :--- |
| `репорт <причина>` | Ответом на сообщение | Отправляет жалобу администраторам в личные сообщения со ссылкой на сообщение нарушителя. Также работают `!репорт` и `/report`. |
| `/rules` | В чате | Показывает актуальные правила группы. |
| `/info` | В чате или ответом | Показывает информацию о пользователе или статистику чата. |
| `/help` | В личке с ботом | Выводит краткую справку по работе с ботом. |

---

## 🛡 Команды для администраторов

> Большинство команд наказаний можно писать **как со слэшем (`/warn`), так и обычным русским словом (`варн`)** ответом на сообщение нарушителя.

| Команда | Формат / Пример | Что делает |
| :--- | :--- | :--- |
| `-чат` | В чате | **Закрывает чат:** обычные участники не могут отправлять сообщения и медиа, писать могут только администраторы. Также: `!чат стоп`, `/lock`. |
| `+чат` | В чате | **Открывает чат:** возвращает всем участникам право писать в группу. Также: `!чат старт`, `/unlock`. |
| `/warn` (`варн`, `пред`) | Ответом на сообщение | Выдаёт предупреждение (`1/3`, `2/3`). При **3/3** автоматически отправляет нарушителя в бан на 3 дня (при повторном нарушении — навсегда). |
| `/unwarn` (`анварн`, `снять пред`) | Ответом на сообщение | Снимает одно предупреждение у пользователя. |
| `/mute` (`мут 30м`, `мут 2ч`, `мут 1д`) | Ответом на сообщение | Запрещает пользователю писать на указанное время (по умолчанию — на 1 час). |
| `/unmute` (`анмут`, `размут`) | Ответом на сообщение | Досрочно снимает мут и возвращает права на отправку сообщений. |
| `/ban` (`бан`) | Ответом на сообщение | Навсегда блокирует пользователя в группе. |
| `/unban` (`анбан`, `разбан`) | Ответом на сообщение | Снимает блокировку с пользователя. |
| `/kick` (`кик`) | Ответом на сообщение | Исключает участника из группы с возможностью вернуться по ссылке. |
| `/settings` | В чате | Открывает интерактивное меню включения/выключения фильтров прямо в чате. |
| `/setrules` | Ответом на текст | Устанавливает новый текст правил группы из сообщения, на которое дан ответ. |
| `/resetrules` | В чате | Сбрасывает правила группы на стандартные. |
| `/pinrules` | В чате | Публикует правила и закрепляет сообщение в шапке группы. |
| `/status` | В чате | Проверяет права администратора у бота в группе и канале и синхронизирует чат с админ-панелью. |

## 🚀 Пошаговая установка за 0 ₽

### 1. Создание бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) и выполните команду `/newbot`.
2. Скопируйте полученный токен (`BOT_TOKEN`).
3. В разделе **Bot Settings → Group Privacy** выберите **Turn off**, чтобы бот мог видеть сообщения в группе для работы антимата и текстовых команд.

### 2. Создание бесплатной базы PostgreSQL (Neon)
1. Зарегистрируйтесь на [neon.tech](https://neon.tech) и создайте новый проект.
2. Скопируйте строку подключения **Connection string** вида `postgresql://user:password@ep-...neon.tech/neondb?sslmode=require` — это ваш `DATABASE_URL`.

### 3. Деплой на Render
1. Сделайте Fork этого репозитория на GitHub.
2. Зайдите на [dashboard.render.com](https://dashboard.render.com), нажмите **New → Web Service** и выберите ваш репозиторий.
3. Укажите настройки запуска:
   * **Runtime:** `Python 3`
   * **Build Command:** `pip install -r requirements.txt`
   * **Start Command:** `python main.py`
4. Во вкладке **Environment** добавьте переменные:
   * `BOT_TOKEN` — токен от `@BotFather`
   * `DATABASE_URL` — ссылка на базу PostgreSQL из Neon
   * `CHANNEL_ID` *(необязательно)* — ID канала вида `-1001234567890` для проверки подписки
   * `CHANNEL_URL` *(необязательно)* — публичная или пригласительная ссылка на канал
5. Нажмите **Deploy Web Service**.

### 4. Защита от засыпания 24/7 (cron-job.org)
Бесплатный тариф Render усыпляет сервер через 15 минут без входящих HTTP-запросов. Чтобы бот работал круглосуточно:
1. Скопируйте URL вашего сервиса на Render (например, `https://your-bot.onrender.com`).
2. Зарегистрируйтесь на [cron-job.org](https://cron-job.org), нажмите **Create cronjob**, вставьте ссылку `https://your-bot.onrender.com/health` и выберите интервал **Every 10 minutes**.

### 5. Подключение к группе
1. Добавьте бота в вашу группу и назначьте **администратором** с правами: *удаление сообщений*, *блокировка пользователей*, *приглашение по ссылкам*, *закрепление сообщений*.
2. Если используете проверку подписки при заявках — добавьте бота администратором в канал.
3. Напишите в группе `/status`, а затем откройте личные сообщения с ботом и нажмите **«🛡 Открыть админ-панель»**.
