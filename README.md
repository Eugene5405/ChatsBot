# 🛡 Чат-менеджер для Telegram (Хранитель чата)

Полнофункциональный Telegram-бот для модерации групп и супергрупп на **Python 3.11+ (`aiogram 3`)**, **PostgreSQL (`Neon`)** и **Telegram Mini App (Web App)**, который можно бесплатно развернуть на **Render** с круглосуточной работой 24/7.

---

## ✨ Возможности бота

### 1. Модерация и управление чатом (в стиле Iris Chat Manager)
* **`-чат` / `+чат`** — мгновенное закрытие общения для обычных участников (писать могут только администраторы) и возврат общения.
* **Система репортов (`репорт <причина>`)** — участники могут ответить на сообщение нарушителя командой `репорт <причина>`. Бот публикует уведомление в чате и отправляет всем администраторам в личные сообщения карточку жалобы со ссылкой на сообщение и кнопками быстрых действий (**🗑 Удалить**, **🔇 Мут 1ч**, **🚫 Бан**, **✅ Отклонить**).
* **Варны, муты и баны** — выдача предупреждений (`/warn`), временных ограничений (`/mute`), блокировок (`/ban`) и просмотр статистики.

### 2. Умный автомод и фильтры
* **Умный антимат (`profanity.py`)** — распознаёт нецензурную лексику внутри любых предложений, обходит маскировку латинскими буквами (`a -> а`, `c -> с`, `e -> е`), повторы букв (`сууука`), пробелы между буквами и содержит белый список обычных слов.
* **Антиспам и антиреклама (`automod.py`)** — защита от флуда, пересылки рекламных постов и сторонних ссылок.

### 3. Вход, выход и проверка подписки (`welcome.py`)
* **Проверка подписки на канал** — при входе по заявкам (`ChatJoinRequest`) бот проверяет подписку пользователя на указанный канал и предлагает кнопку проверки перед одобрением.
* **Приветствие с реальным названием чата** — автоматически подставляет актуальное название группы и разворачиваемую цитату с правилами (`/setrules`).
* **Прощание при выходе** — отправляет аккуратное сообщение в чат, когда участник покидает группу.

### 4. Админ-панель Telegram Mini App (`webapp.py` и `pm_panel.py`)
* Встроенная веб-панель управления (`/webapp`), открывающаяся прямо внутри Telegram из личных сообщений с ботом.
* Удобное нижнее меню кнопок в ЛС: **🛡 Админ-панель**, **➕ Добавить в чат**, **📋 Мои чаты**, **❓ Помощь**.

## 📁 Структура проекта

| Файл | Назначение |
| :--- | :--- |
| `main.py` | Точка входа: инициализация БД, подключение всех роутеров и запуск веб-сервера `aiohttp`. |
| `config.py` | Загрузка переменных окружения (`BOT_TOKEN`, `DATABASE_URL`, `CHANNEL_ID`). |
| `loader.py` | Инициализация экземпляра `Bot` с настройками форматирования HTML. |
| `db.py` | Подключение к PostgreSQL (Neon), хранение предупреждений, правил и настроек чатов. |
| `admin.py` | Административные команды и проверка прав в группе (`/status`, `/settings`). |
| `moderation.py` | Команды наказаний: предупреждения, муты, баны и разбаны. |
| `automod.py` | Автоматическая фильтрация сообщений в реальном времени. |
| `profanity.py` | Модуль нормализации текста и поиска нецензурной лексики. |
| `chat_lock.py` | Команды блокировки (`-чат`) и разблокировки (`+чат`) общения. |
| `report.py` | Обработка жалоб участников и рассылка карточек админам в ЛС. |
| `welcome.py` | Заявки на вступление, приветствие новичков и прощание при выходе. |
| `pm_panel.py` | Меню и клавиатура в личных сообщениях с ботом. |
| `webapp.py` | Веб-сервер и интерфейс Telegram Mini App + эндпоинт `/health`. |
| `info.py` | Справочные команды и информация о чате/пользователе. |
| `rules.py` | Управление правилами чата. |
| `utils.py` | Вспомогательные функции форматирования. |

## 🚀 Пошаговая инструкция по бесплатному запуску (0 ₽)

Вы можете развернуть своего бота за 10 минут без покупки сервера, используя бесплатные тарифы **GitHub + Neon + Render + cron-job.org**.

### Шаг 1. Создайте бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Задайте имя и юзернейм бота, после чего скопируйте полученный **HTTP API Token**.
3. В настройках бота (**Bot Settings → Group Privacy**) выберите **Turn off**, чтобы бот мог видеть сообщения в группах и фильтровать нарушения.

### Шаг 2. Создайте бесплатную базу данных PostgreSQL (Neon)
1. Зарегистрируйтесь на [neon.tech](https://neon.tech) и создайте новый проект.
2. На главном экране проекта скопируйте строку подключения **Connection string** (вида `postgresql://user:password@ep-xxx.aws.neon.tech/neondb?sslmode=require`).

### Шаг 3. Подготовьте репозиторий на GitHub
1. Сделайте **Fork** этого репозитория (или загрузите все файлы в свой репозиторий на [github.com](https://github.com)).
2. Убедитесь, что в корне репозитория есть файл `requirements.txt` со следующими зависимостями:
   ```text
   aiogram>=3.7.0
   aiohttp>=3.9.0
   psycopg2-binary>=2.9.9
   python-dotenv>=1.0.1
   ```

### Шаг 4. Разверните бота на Render
1. Зайдите на [dashboard.render.com](https://dashboard.render.com), нажмите **New + → Web Service** и подключите ваш репозиторий GitHub.
2. Укажите настройки запуска:
   * **Runtime:** `Python 3`
   * **Build Command:** `pip install -r requirements.txt`
   * **Start Command:** `python main.py`
   * **Instance Type:** `Free`
3. Перейдите в раздел **Environment** и добавьте переменные окружения:

| Переменная | Обязательно | Описание и пример значения |
| :--- | :---: | :--- |
| `BOT_TOKEN` | Да | Токен вашего бота от `@BotFather` |
| `DATABASE_URL` | Да | Ссылка подключения к PostgreSQL из Neon (`postgresql://...`) |
| `CHANNEL_ID` | Нет | ID канала для обязательной подписки при входе (например, `-1001234567890`) |
| `CHANNEL_URL` | Нет | Ссылка-приглашение на канал (если канал закрытый) |
| `RENDER_EXTERNAL_URL` | Нет | Публичный адрес вашего сервиса на Render (например, `https://my-bot.onrender.com`) |

4. Нажмите **Deploy Web Service**. После завершения сборки сервис получит статус **Live**, а вверху появится ссылка вида `https://ваш-бот.onrender.com`.

### Шаг 5. Настройте круглосуточную работу 24/7 (cron-job.org)
Бесплатный тариф Render усыпляет сервис после 15 минут бездействия. Чтобы бот работал без остановок:
1. Зарегистрируйтесь на [cron-job.org](https://cron-job.org) и нажмите **Create cronjob**.
2. В поле **URL** вставьте публичную ссылку вашего сервиса на Render (например, `https://ваш-бот.onrender.com/health` или главную ссылку `https://ваш-бот.onrender.com`).
3. Выберите расписание **Every 10 minutes** и сохраните задачу.

## 🛠 Настройка в Telegram после запуска

1. **Добавьте бота в группу** и выдайте ему права администратора:
   * Удаление сообщений
   * Блокировка пользователей (нужно для мутов, банов и команды `-чат`)
   * Приглашение пользователей по ссылкам
   * Закрепление сообщений
2. **Если используете проверку подписки:** добавьте бота администратором в ваш канал.
3. **Для получения репортов в ЛС:** каждый администратор чата должен открыть личные сообщения с ботом и нажать `/start` (иначе Telegram запрещает боту писать пользователю первым).
4. **Проверка работы:** напишите в группе команду `/status` — бот проверит все свои права и подтвердит готовность к работе.

## 📋 Основные команды

* `/start` — открыть главное меню и админ-панель (в личных сообщениях с ботом).
* `/status` — проверить права бота в группе и синхронизировать чат.
* `/settings` — открыть настройки фильтров и модулей защиты.
* `/setrules` *(ответом на сообщение)* — установить правила чата.
* `-чат` / `+чат` — закрыть или открыть чат для обычных участников (только для админов).
* `репорт <причина>` *(ответом на сообщение)* — пожаловаться на сообщение администраторам.
